# Security and data handling

This repository is a research prototype, not a hosted service. The interface is static and does not accept data uploads.

- Never commit credentials, access tokens, Earth Engine private assets, personal data or non-public research data.
- Keep raw rasters and large processed tables outside version control unless redistribution rights are explicit.
- Use the official provider portals and project-level access controls for data retrieval.
- Report suspected repository security issues privately to the repository owner rather than publishing sensitive details in an issue.

The analysis expects prepared environmental data. It is not designed to store participant, patient or household information.
